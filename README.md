# 翻訳（iPad「翻訳」アプリ風 PWA）

ビルド不要の静的ファイルだけで動く PWA です（HTML / CSS / JavaScript のみ）。

## 機能
- **翻訳**: テキスト入力でリアルタイム翻訳、Return で履歴に確定。言語メニュー（21言語）、入れ替え、音声入力、読み上げ、拡大表示、お気に入り、コピー、性別の選択（英語→スペイン語・ポルトガル語・フランス語・イタリア語・ドイツ語の一部の職業語）
- **カメラ**: ライブ映像上にテキストを翻訳表示（Tesseract.js による OCR）、シャッターで一時停止、写真の読み込み、ライト。カメラが使えない環境ではデモ画面
- **会話**: 上下分割（上は180°回転）の対面会話、マイク/キー入力、自動読み上げ
- **お気に入り**: 言語ペアごとの一覧と「最近の項目」
- 左上のアイコンでサイドバー ⇄ 上部タブバーを切り替え（幅700px未満は常にタブバー）
- ライト/ダークモード対応、オフライン起動（Service Worker）

## GitHub Pages への公開
1. このフォルダの中身をリポジトリのルートに置いて `main` に push
2. **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にする（`.github/workflows/pages.yml` 同梱）。
   Actions を使わない場合は「Deploy from a branch」→ `main` / `(root)` でも動きます
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` を iPad の Safari で開き、共有ボタン → **ホーム画面に追加**

パスはすべて相対指定なので、サブパス配下でもそのまま動作します。

## 外部サービス
| 用途 | 内容 |
|---|---|
| 翻訳 | [MyMemory](https://mymemory.translated.net/doc/spec.php)（無料・匿名は1日の上限あり。超えるとエラー表示） |
| OCR | Tesseract.js（初回のカメラ使用時に jsDelivr から取得） |
| 読み上げ / 音声入力 | ブラウザ標準の Web Speech API（iOS のホーム画面アプリでは音声入力が使えないことがあります。その場合はキー入力を使用） |

翻訳エンジンを変える場合は `app.js` の `xlate()` だけ差し替えてください。

## 注意
- Apple 公式アプリのオンデバイス翻訳などは Web では再現できないため、見た目と操作を近づけた実装です。
- 履歴・お気に入り・設定は端末の localStorage に保存されます。
